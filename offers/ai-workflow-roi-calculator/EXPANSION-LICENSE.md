# Automation Expansion License — ¥19,800/month

A recurring commercial path for buyers who complete the ¥49,000 fixed-scope Automation Pilot and want to keep improving the same workflow without commissioning a new open-ended project each time.

## Offer

**Expansion License: ¥19,800/month**

One active workflow at a time. Each paid month includes:

- up to 2 bounded change requests to the existing automation;
- one monthly health/ROI check using the buyer's non-confidential aggregate metrics;
- compatibility fixes caused by ordinary changes in the agreed workflow interface, where feasible within the existing architecture;
- one updated operating note when behavior changes;
- priority qualification for the next reusable automation component.

This is deliberately not unlimited development, managed IT, production monitoring, or an SLA.

## Eligibility

The buyer must first complete or have an accepted equivalent of the ¥49,000 Automation Pilot. The workflow must remain within the original safety boundary and be testable with synthetic, public, anonymized, or otherwise non-confidential data.

## What counts as one change request

A request is bounded when it modifies the existing workflow without introducing a new system, new workflow, material architecture change, sensitive-data requirement, or regulated/high-risk decision function. Examples: add one output field, change a formatting rule, adjust a mapping, or update one bounded transformation step.

Anything materially larger is separately scoped before work begins.

## Privacy and safety

Do not post credentials, API keys, personal data, employer/customer confidential information, proprietary documents, private URLs, production records, or vessel/operational information in public GitHub issues. Qualification should use generic, synthetic, public, or anonymized examples only.

## Why this exists

The fixed-scope Pilot proves one automation economically. The Expansion License creates a repeatable maintenance-and-improvement surface after proof, while keeping scope measurable and outsourceable.
