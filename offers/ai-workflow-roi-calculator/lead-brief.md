# Free AI Workflow ROI Assessment — Intake

Use this short intake to turn the ROI calculator result into a scoped automation opportunity without sharing confidential information.

## What to send

Copy the block below into a GitHub issue in this repository. Replace only the bracketed fields.

```text
Title: ROI assessment — [workflow name]

Workflow: [generic description; no confidential data]
Runs per month: [number]
Minutes per run now: [number]
Estimated minutes per run after automation: [number or unknown]
Hourly labor value (JPY): [number or unknown]
Current tools: [generic tool names only]
Biggest repetitive step: [one sentence]
Desired outcome: [time saved / fewer errors / faster response / other]
Data sensitivity: [public / synthetic / confidential — do not paste confidential data]
```

## What you get

A bounded assessment identifying: (1) the smallest automatable step, (2) estimated monthly hours recoverable, (3) a reversible implementation outline, and (4) a go/no-go threshold. Estimates are not guarantees and should be validated against a real baseline before implementation.

## Safety boundary

Do not include passwords, API keys, personal data, employer/client confidential information, proprietary documents, or production credentials. Use generic descriptions or synthetic examples. No access to production systems is required for the assessment.

## Why this exists

The calculator quantifies whether a workflow is worth examining. This intake converts that result into a standardized, repeatable buyer request that can later be fulfilled manually or delegated without redesigning discovery each time.
