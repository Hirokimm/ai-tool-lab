# HA125 — Application-Ready Evidence Index

Purpose: provide one compact, sanitized entry point to the public work samples relevant to a generative-AI workflow + Git engagement.

## Evidence map

1. **AI workflow demonstration** — `portfolio/ha125-ai-workflow-demo.md`
   - Demonstrates a fictional workflow with structured outputs, hallucination controls, human review, and evaluation criteria.

2. **Application evidence pack** — `portfolio/ha125-application-evidence-pack.md`
   - Maps public artifacts to capability areas without asserting unverified employment history or eligibility.

3. **Git work sample** — `portfolio/ha125-git-work-sample.md`
   - Demonstrates bounded changes, acceptance criteria, diff review, verification, reversible commits, and privacy controls.

4. **Delivery checklist** — `portfolio/ha125-delivery-checklist.md`
   - Shows a repeatable delivery process from requirement confirmation through verification and handoff.

5. **Interview evidence map** — `portfolio/ha125-interview-evidence-map.md`
   - Provides a safe map from likely screening topics to concrete public evidence.

## Safe claims supported by these artifacts

- Can design a small generative-AI workflow around explicit inputs, outputs, review gates, and evaluation criteria.
- Can document a Git-oriented change process with scoped changes, review, verification, and reversibility.
- Can separate demonstrable artifact evidence from claims that require human confirmation.

## Claims deliberately NOT made here

This repository does **not** establish or claim:

- prior paid/commercial experience,
- experience at any named employer or client,
- access to private workplace or shipboard information,
- availability for a specific monthly hour commitment,
- satisfaction of any marketplace/job eligibility criterion that depends on the applicant's real-world history.

Those facts require direct human confirmation before any application is submitted.

## Privacy / employment firewall

All examples are sanitized or fictional. No employer, vessel, customer, colleague, operational, confidential, or personally identifying information is used as evidence.
