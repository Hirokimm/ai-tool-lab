# HA125 — Sanitized Delivery Checklist

Purpose: a reusable, privacy-safe checklist for a small generative-AI + Git workflow engagement. This is a demonstration artifact only; it does not claim employment history, client work, or eligibility.

## 1. Intake
- Restate the requested outcome in one sentence.
- Define the input format and expected output format.
- Record acceptance criteria before implementation.
- Exclude secrets, personal data, employer information, shipboard information, and confidential client material.

## 2. Smallest reversible change
- Create the minimum change that can be reviewed independently.
- Keep source material and generated output separable.
- Avoid destructive edits; preserve a rollback path.

## 3. AI workflow controls
- Use explicit instructions and structured output where practical.
- Mark uncertain output for human review rather than inventing facts.
- Check a small representative sample manually before wider use.
- Record known failure modes and edge cases.

## 4. Git workflow
- Inspect the diff before commit.
- Keep the commit scoped to one coherent change.
- Use a descriptive commit message.
- Verify the repository state after commit.
- Retain a clear revert path.

## 5. Verification
- Test against the acceptance criteria.
- Check that no sensitive data entered prompts, files, logs, examples, or commit messages.
- Confirm the delivered artifact opens/runs as expected.
- Separate observed results from assumptions.

## 6. Handoff
- State what changed.
- State how it was verified.
- State any remaining limitation.
- Provide the next smallest action only when needed.

## Evidence boundary
This sample intentionally uses no employer, vessel, customer, or private information. It demonstrates a delivery method, not a claim that any specific prior commercial engagement occurred.
